Covenant waiver approvals

A waiver is the one action where a person overrides the covenant: it permits a draw that coverage says should be refused. So it takes two approvers. Each approver signs in their own browser with a key that never leaves it. This server holds Privy's app secret and no approver key. Privy signs the transaction only after both approvals, and this server checks the signed transaction against what was approved before broadcasting it to Arc.
