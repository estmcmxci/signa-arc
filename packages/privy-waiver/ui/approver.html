Approvers in this browser

A waiver needs both approvers. Each signs Privy's authorization payload with their own P-256 key; the key never leaves the browser and this server never sees it. For this demo both keys are in one browser; in use, each approver holds only their own.

Propose a waiver

Before proposing, the server reads the chain: the vault must belong to this facility, the facility must not be compliant, no waiver may be active, and the duration must be within maxWaiverDuration. A proposal the contract would refuse is never sent to the approvers.
